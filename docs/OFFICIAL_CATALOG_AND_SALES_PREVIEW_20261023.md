# 2026-10-23 課程平台與銷售預覽：建置說明

## 資料來源和最重要的區別
- 課程商品：**終極和弦伴奏公式**；品牌：**教會鋼琴 PIANO LESSONS**。
- 2026-10-23 提供的教師知識庫草稿 v0.3.1：四單元共 **23 堂**，依序 6 / 5 / 6 / 6 堂。
- 草稿講義 27 頁，不等於 27 堂課。兩堂影片（1-1 彈奏姿勢、2-1 延音踏板）在知識庫中標記為尚待錄製。
- 存進 GitHub 的只有目錄名稱、ID 與核對完成的結構，不包含原始 SRT 字幕、整份講義、未核准 AI 摘要。
- 本 repo 的舊版 MVP 曾暫時建立每單元 8 個可編輯位置；本更新只改成正式草稿目錄的 23 堂，**不刪除／覆寫 Redis 的影片資料**。已上架的測試影片仍在原本 `u1-l01` 位置；管理員日後可手動把它改回正式課名與影片。

## 內部銷售頁預覽
- `/sales-preview` 是內部行銷預覽：無金流、無購物車、無購買／開通自動化。
- 標示 2026-10-23 目錄是草稿、兩堂影片待錄製、講義非定稿。
- 四個課程單元與 23 堂課名稱均取自教師知識庫。
- 全套 NT$3,000 是先前討論的「規劃售價」，入門組及進階組不捏造價格。
- 不生成虛構的學生推薦語、學習成果、退款／期限承諾或「所有影片已可觀看」的訊息。
- SEO noindex/nofollow/noarchive，正式公開發售需另外核准方案、實際課程交付及銷售條款。

## 學員使用體驗
- 支援桌機和平板版的影片／側欄目錄並排；手機使用單欄、播放器在前。
- 可以手動標記已完成的**已上架**課程；進度存入會員原有 staging Redis。
- `POST /api/student/progress` 需 LINE session、單元購買資格、正確站內 Origin、JSON，未上架課程不可標記完成。
- 檢查購課資格仍在後端，不能繞過前端鎖定開啟課程。
- 學員中心影片載入經先前實測 iPhone 正常；新版布局仍需另行在 iPhone、iPad（直橫向）及 Mac/Windows 測試。
- 教師應保留 PDF 講義原件及原始字幕檔，不要放在 GitHub 公開 repo。

## 發售順序
1. 確認正式單元、課次及未完成影片／講義的上架時間。
2. 測試三種裝置與 LINE／Safari／Chrome 登入、播放器、講義、跨裝置進度。
3. 確認第一波販售可提供的權益、觀看期限、退款與稅務條款，訂出各組售價。
4. 可先使用既有人工發送開課碼，但必須真正核實訂單，且不能把同一筆訂單重複發碼。
5. 比較 Portaly、藍新、綠界金流與個人戶開通資格後再決定收款方式；**此版本不啟用任何真實金流**。
6. 用少量內測學員收集真實操作回饋（經本人同意後才能放進銷售頁），之後才對 IG 受眾做首購測試。
