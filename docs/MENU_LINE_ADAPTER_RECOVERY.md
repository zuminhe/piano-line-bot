# LINE 測試選單：受限 API 適配器與中斷檢查（未部署）

本次新增：
- `lib/line-menu-switch-adapter.js`：僅讀取指定測試帳號的個人選單、專屬測試圖文選單與圖片；僅在獨立開關與單一帳號白名單同時符合時，允許特定個人選單 link POST。
- `lib/menu-recovery-inspector.js`：唯讀檢查 journal、原始備份及現有選單，比對狀態，但**不會自動還原或重試任何寫入**。
- 模擬測試涵蓋關閉時完全不送網路請求、非白名單拒絕、只准核准選單 ID、正常／異常中斷狀態。

## 仍未實作或通過的實際啟用條件

1. 取得正式 LINE 測試選單 ID 並完成圖片上傳（目前不存在，不能當作已建立）。
2. 驗證 original menu snapshot 在獨立 staging 資料庫的保存，以及真實 LINE 資料回讀。
3. **稽核併發控制與逾時安全**：現有模擬切換服務的短效鎖定不足以保證所有網路中斷或並行操作安全；尚需真正的 lease fencing 與原子化紀錄處理。
4. 測試真實 LINE API 回應格式、大小寫、錯誤/401/404/超時；尤其不能將 404 當成無原個人選單。
5. 只在人工審查、可回復能力具備後，才將適配器接到 `lib/menu-switch-service.js`，並加後台按鈕。**本分支目前沒有任何可由管理後台呼叫的新 LINE 寫入操作。**

此分支不得直接部署到正式或 staging 專案，亦不可合併到 `main`；沒有在正式 LINE 或 Vercel 變更設定。
